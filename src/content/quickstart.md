# *httk* quickstart

## Install

Install the `httk2` metapackage from PyPI:

```bash
pip install httk2

```
This installs the complete standard set of httk₂ modules with their
recommended default features. We recommend installing into a virtual
environment; see the [installation section](index.html#installation) on the
front page for step-by-step instructions with `venv`, `uv`, or `conda`.
